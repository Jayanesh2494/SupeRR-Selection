# Local source data

Place the six competition CSVs in this directory to run the analysis locally.

Source datasets are deliberately excluded from version control because their redistribution rights have not been established. The scripts also accept the CSVs at the project root.

Required filenames:

- `ball_by_ball.csv`
- `matches.csv`
- `competitions.csv`
- `teams.csv`
- `playing_eleven.csv`
- `competition_team_player_mapping.csv`
